Superstore Sales Analysis – Task 5

 Project Overview

This project analyzes the Sample Superstore dataset to identify sales, profit, quantity, order performance, regional performance, category performance, and monthly sales trends.

The analysis was completed using **Google Sheets** with formulas and PivotTables.

Objective

The main objectives of this project are:

- Analyze overall sales and profit performance
- Calculate key business KPIs
- Compare sales and profit across different regions
- Analyze category-wise performance
- Identify monthly sales trends
- Generate meaningful business insights using PivotTables

Dataset

The project uses the **Sample Superstore** dataset.

The dataset contains information about:

- Orders
- Customers
- Products
- Categories
- Regions
- Sales
- Quantity
- Discount
- Profit
- Order Dates

 Tools Used

- Google Sheets
- PivotTables
- Google Sheets Formulas
- GitHub

 Analysis Performed

 1. KPI Analysis

The following key performance indicators were calculated:

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Average Sales
- Average Profit

 2. Region-wise Analysis

Sales and profit were analyzed across the following regions:

- Central
- East
- South
- West

The analysis includes:

- Total Sales
- Total Profit
- Order Count
- Average Sales

3. Category-wise Analysis

PivotTables were used to analyze:

- Sales by Category
- Profit by Category

 4. Monthly Sales Trend

A PivotTable was created to analyze sales performance by month and identify changes in sales throughout the year.

5. PivotTable Analysis

The project includes the following PivotTables:

1. Sales by Category
2. Profit by Category
3. Sales by Region
4. Profit by Region
5. Sales by Month

Formulas Used

The following Google Sheets formulas were used:

- `SUM`
- `AVERAGE`
- `COUNTUNIQUE`
- `SUMIFS`
- `COUNTIFS`
- `AVERAGEIFS`

Key Findings

- The **East region generated the highest sales** among the four regions.
- The **West region generated the highest profit**.
- The business generated **positive overall profit** across the analyzed dataset.
- Monthly sales analysis helps identify changes in sales performance throughout the year.
- Category-level analysis helps compare sales and profitability across different product categories.

 Conclusion

The analysis provides a clear overview of the Sample Superstore business performance.

Using Google Sheets, formulas, and PivotTables, the project identifies important sales and profitability patterns that can support better business decision-making.
